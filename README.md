ProManage is a full-stack Project Management Platform that helps teams efficiently manage projects, assign tasks, track progress, and collaborate in one place.
It provides secure authentication, role-based access control, task management, and an interactive dashboard to improve productivity and streamline project workflows.

JavaScript (ES6+)

HTML5 & CSS3

Backend:
